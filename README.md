# Cheat Arena fixed GitHub Pages baseline

이 버전은 문제 추적을 쉽게 하기 위해 외부 CSS/JS 없이 `index.html` 하나에 게임을 통합했습니다.

GitHub Pages 저장소 루트에 `index.html`과 `.nojekyll`을 올리면 됩니다.

## 현재 기능
- AI 3v3
- AR / Pistol / Knife
- AIM / ESP
- PC WASD + Mouse
- 모바일/태블릿 듀얼 스틱
- 반응형 HUD
- 런타임 오류가 발생하면 화면 하단에 GAME ERROR 표시

온라인 Render 코드는 이 버전이 정상 실행되는 것을 확인한 뒤 붙이는 것을 권장합니다.
